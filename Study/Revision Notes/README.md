## The study loop

Read a worked page → reproduce its examples without looking → attempt the checkpoint → compare full solutions → log errors → revisit the missed method. Start the next topic after checking understanding; prepare future topics one at a time.

The official syllabus controls coverage. Official DA papers and final keys control PYQ answers. Other-exam material is labeled supplementary. The [general revision SOP](SOP.md) is the shared instruction for every subject and topic: source review, compact ImageGen pages, full-question solutions, verification, folder structure, print order and progress updates.

Each topic has sibling Markdown and PNG folders. The PNG folder includes lessons, checkpoint and solutions in print order. Solutions repeat the complete questions. No PDFs are generated.
