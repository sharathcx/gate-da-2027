## Unit workflow

1. Before each unit, prepare a four-day plan from syllabus breadth, prerequisites, verified PYQs, and the user's reported progress.
2. Break each study day into a small number of goals with time blocks. A day counts only after the user's check-in.
3. For each subtopic, keep an editable Markdown lesson and checkpoint, with matching PNG page images embedded in the Markdown. Paste the PNGs in chat when delivering them.
4. Keep checkpoint answers out of the checkpoint files. After the user attempts the checkpoint, provide a separate Markdown solution set with PNG pages and diagnose error patterns.
5. Include a mixed checkpoint within the unit's four-day block. Reduce optional practice before reducing official coverage.

## Completion criteria

A unit is complete when every official syllabus item has been covered, relevant DA PYQs have verified solutions, topic checkpoints have been attempted and reviewed, and the unit mixed checkpoint is complete. Record remaining errors for cumulative practice without extending the unit beyond four focused study days.
